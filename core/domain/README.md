# Katalog Domain Profile

[BARU MULTI-USER] Domain Profile berisi aturan **bidang ilmu**. Aturan **satu kampus/prodi** (kewajiban SINTA, gaya sitasi wajib, batas similarity, struktur bab) masuk `prodi/`, bukan di sini.

| Domain | Status |
|---|---|
| `komunikasi` | Dari v2; tes penerimaan belum dijalankan |
| `informatika` | [TAMBAHAN 1-OKT]; tes penerimaan belum dijalankan |
| `umum` | [BARU SELF-SERVICE] Cadangan untuk bidang yang belum punya profil; pengguna bisa langsung mulai |

Kandidat yang dibuat saat ada pengguna nyata: manajemen, administrasi-publik, hukum, pendidikan, ekonomi-akuntansi, kesehatan-masyarakat. Pengguna boleh membuat draf sendiri dengan peran `domain-profile-builder` (`core/onboarding.md`); tim menguji sebelum masuk katalog.

Status modul: **teruji** (lolos tes penerimaan), **belum teruji** (dari tim, tes belum dijalankan), **draf** (buatan pengguna, belum direview tim).
